# Fonts

Place the following font files in the matching subdirectories.  
Download from Google Fonts (all OFL licensed):

## Poppins (display / headings — English)
https://fonts.google.com/specimen/Poppins
- `Poppins/Poppins-Regular.ttf`     (400)
- `Poppins/Poppins-Medium.ttf`      (500)
- `Poppins/Poppins-SemiBold.ttf`    (600)
- `Poppins/Poppins-Bold.ttf`        (700)
- `Poppins/Poppins-ExtraBold.ttf`   (800)

## Inter (body — English)
https://fonts.google.com/specimen/Inter
- `Inter/Inter-Regular.ttf`         (400)
- `Inter/Inter-Medium.ttf`          (500)
- `Inter/Inter-SemiBold.ttf`        (600)
